# Marble it Up! Nucleus Co-op handler

**I no longer recommend Nucleus.**  

The new [SplitScreen.Me](https://github.com/SplitScreen-Me) organization seems to have divolved into a toxic organization that is essentially hostile to new contribution. 

After building this input handler they forced me to go through their Discord server for "approval" (already a significant red flag) where moderators reflexively dismissed this handler (and the entire Marble it Up! game) as unacceptable for "security concerns". 
They refused to articulate these concerns in any way, and instead just talked about the dangers of "hacking", even though they're ostensibly a game modification community. Eventually they deleted my work outright and purged the conversation history. 
This handler does not touch any security or networking concerns; it only splits input and enables simultaneous play. 

As part of this handler, I've noted that the Marble it Up! servers use open matchmaking, allowing Goldberg Steam accounts to connect. Moderatiors indicated this was *not* their concern.

I am posting this here so the work isn't lost, but I will no longer spend any time trying to work with SplitScreen.Me or contributing to their project.
